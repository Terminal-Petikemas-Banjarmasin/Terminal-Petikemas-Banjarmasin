Perbarui data dashboard

Kinerja Terminal Petikemas Banjarmasin. Halaman ini hanya menyiapkan file. Website baru berubah setelah data.json diunggah ke GitHub.

Kembali ke dashboard

1. Pilih file Excel kinerja

Format sama seperti laporan kinerja bulanan atau file Januari–November. Hanya bulan yang ada di file yang diganti. Bulan lain tetap.

2. Unduh data baru

Untuk GitHub cukup file data.json. Paket .zip hanya perlu bila semua file website ingin diganti.

3. Unggah ke GitHub

  1. Buka github.com, masuk, lalu buka repositori dashboard ini.
  2. Klik Add file, lalu Upload files.
  3. Seret file data.json ke halaman itu, lalu klik Commit changes. File lama otomatis diganti.
  4. Tunggu beberapa menit (bisa sampai 10 menit), lalu buka dashboard dan periksa tanggal "Diperbarui" di kanan atas.
